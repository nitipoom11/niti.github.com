ผลงานของผม

เว็บไซต์ Portfolio

เว็บไซต์นี้เป็นหนึ่งในผลงานที่ผมสร้างขึ้นเพื่อแสดงความสามารถของผม

แอปพลิเคชันจัดการงาน

แอปพลิเคชันที่ช่วยให้ผู้ใช้งานจัดการงานได้อย่างมีประสิทธิภาพ

ทักษะของผม

  • HTML, CSS, JavaScript
  • Python, Django
  • Git และ GitHub
  • การออกแบบ UI/UX

ผลงานคอมพิวเตอร์

โปรแกรมคำนวณคะแนนเฉลี่ยสะสม (GPAX Calculator)

พัฒนาโปรแกรมเดสก์ท็อปขนาดเล็กเพื่อช่วยให้นักเรียนสามารถคำนวณและวางแผนผลการเรียนได้อย่างถูกต้องและรวดเร็ว

โครงงานระบบเปิด-ปิดไฟอัตโนมัติด้วย IoT

ประยุกต์ใช้บอร์ดไมโครคอนโทรลเลอร์ร่วมกับเซนเซอร์ตรวจจับความเคลื่อนไหว เพื่อช่วยประหยัดพลังงานภายในห้องเรียน

สื่อมัลติมีเดียและกราฟิกดีไซน์

ออกแบบภาพอินโฟกราฟิกและตัดต่อวิดีโอสั้นเพื่อใช้ในการนำเสนอรายงานและกิจกรรมต่าง ๆ ของโรงเรียน
